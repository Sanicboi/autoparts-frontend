# Описание продукта
Автолитика - B2B система проценки автозапчастей по артикулу
# Страницы
Сайт состоит из страницы входа, регистрации и страницы проценки
# Регистрация
Проводится по трем полям - имя пользователя, пароль и ключ доступа
# Вход 
Проводится по имени пользователя и паролю
# Страница проценки
Есть два режима - одиночные артикулы (ввод списком) и загрузка Excel-файла.
Проценка проводится по трем магазинам - Exist.ru, Adeopro.ru и autodoc.ru
После начала проценки она запускается и появляется шкала прогресса либо другой способ измерения
Результаты предоставляются в формате excel, после чего есть возможность его скачать или начать проценку заново
# Требования по дизайну
максимально простой, адаптированный под различные устройства дизайн. Также необходимы переходы/попапы/анимации, но без лишней сложности. Тема только светлая
